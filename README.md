# CitaSalud - GA7-220501096-AA3-EV01
Módulo web de gestión de citas médicas desarrollado con Java 17, Spring Boot, Spring MVC, Thymeleaf, HTML, CSS, JavaScript y Maven.

## Funciones
- Registrar citas médicas.
- Capturar paciente, documento, especialidad, médico, fecha y hora.
- Asignar estado PROGRAMADA.
- Listar citas registradas.

## Ejecutar
`mvn spring-boot:run`

Luego abrir `http://localhost:8080`.

El proyecto incluye comentarios en el código y `.gitignore` para versionamiento con Git.
